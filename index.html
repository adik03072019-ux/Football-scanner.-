Автосканер футбола — ТБ 1.5

Автоматически ищет матчи по всем соревнованиям, доступным через API, и проверяет заданные фильтры.

1. Запуск автоматического поиска

Нужен бесплатный/платный API-токен football-data.org. Программа сама загрузит расписание по всем соревнованиям, которые API разрешит вашему тарифу — выбирать лигу вручную не нужно. Токен используется только для запросов к этому API и не сохраняется.

Готов к запуску. Выбери дату, вставь токен и нажми кнопку.

2. Фильтры поиска

Все статистические условия проверяются автоматически. Коэффициенты в этом источнике не предоставляются, поэтому для финального отбора их нужно внести вручную в карточках матчей. Без коэффициента матч не считается полностью прошедшим отбор.

3. Найденные матчи

Пока нет результатов.

Здесь появятся результаты автоматического поиска.

4. Экспрессы

Экспрессы создаются только из матчей, где статистика прошла фильтры и вручную указан коэффициент в заданном диапазоне.

Сначала просканируй матчи и укажи коэффициенты.
Важно: «все матчи» означает все матчи, которые возвращает выбранный API и разрешает тариф, а не буквально все лиги мира. На бесплатном тарифе могут отсутствовать соревнования и история. Если браузер не разрешает запросы из локального файла, открой файл через хостинг/веб-сервер. Статистические фильтры не гарантируют выигрыш.
